Yoruba Day invitation — GitHub Pages upload

1. Extract this package.
2. Open the Yoruba-Finland-Community repository on GitHub.
3. Choose Add file > Upload files.
4. Upload the contents of this folder, including the hidden .github folder.
5. Commit directly to the main branch.
6. Open Settings > Pages and choose GitHub Actions as the source.

The included workflow deploys this already-built invitation automatically after each push to main.
